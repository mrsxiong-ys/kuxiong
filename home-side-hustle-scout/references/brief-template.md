# 副业说明书模板、待补项规范与真实案例

## 一、九段式副业说明书模板

每个 Top3 项目输出一份，**九段齐全，不允许跳段**。

```markdown
## <项目名>

### 1. 一句话定义
<这个活到底是什么，≤30 字>

### 2. 准入门槛
- 年龄 / 实名 / 粉丝数 / 账号条件：<内容>（来源：<等级 + URL>）
- 其他限制：<内容>

### 3. 每天实际干什么
- 步骤 1：<动作>，约 <时长>
- 步骤 2：<动作>，约 <时长>
- 步骤 3：<动作>，约 <时长>
（颗粒度到分钟，或到「发一篇笔记」「接一单」）

### 4. 需要什么
- 设备：<手机 / 电脑 / 其他>
- 技能：<需要的能力>；没有怎么办：<从零上手的路径>
- 启动资金：<金额；无则写 0 元>

### 5. 收入机制
钱从哪来：<谁付钱>
按什么算：<计算方式 / 公式>
何时入账：<结算时点>

### 6. 收入区间
| 档位 | 数值 | 来源 |
|---|---|---|
| 起步期 | <数值> | <来源；官方未公开则写「官方未公开，待实测」> |
| 常见期 | <数值> | <来源> |
| 上限 | <数值> | <来源> |

### 7. 结算与提现
- 结算周期：<内容 + 来源>
- 提现门槛：<内容 + 来源>
- 手续费 / 税费：<内容 + 来源>
（写不清 → 回退 Step 2 重做核验）

### 8. 时间账
到第一笔收入预计：<多少天 / 多少篇（单）>（依据：<说明>）

### 9. 风险与红线
- 风险 1：<内容>
- 风险 2：<内容>
- 风险 3：<内容>

### 待补项
- [待补] <缺什么> —— 去哪补 / 谁能补
```

## 二、待补项规范

**统一格式**：

```
- [待补] <缺什么> —— 去哪补 / 谁能补 / 补到什么程度算数
```

**规则**：

1. **指不回来源的数字，一律进待补项**，不允许用「一般 / 大概 / 通常」替代。
2. 待补项**不阻断交付**，但必须在报告末尾集中汇总，不得散落在正文里被忽略。
3. 收入数字若官方未公开，写「**官方未公开，待实测**」，并说明实测方法（如「开通后观察 7–14 天后台数据自建基准」）。
4. 常见待补项：
   - 官方未公开的收益单价
   - 个人实测数据（收入、起号耗时）
   - 所在城市 / 类目差异导致的规则差异
   - 税务与结算口径
   - 账号当前实际门槛（以后台显示为准）

## 三、真实案例（已核验）

### 案例：微信视频号「创作分成计划」

**为什么用它做样例**：收入机制清晰、官方有公开规则页、全程手机可完成；同时**官方恰好没有公开收益单价**——正好演示「数字不编、留待补项」的正确做法。

| 字段 | 内容 | 来源 | 状态 |
|---|---|---|---|
| 一句话定义 | 原创视频评论区 / 主页视频流展示广告，作者按广告展示获取分成收入 | 官方 | 已核实 |
| 准入门槛 | 有效关注人数 ≥100（不含当天新增、不含可疑或刷量用户）；符合内容规范；为优质原创作者 | 官方 | 已核实 |
| 额外限制 | 内测阶段分批邀请；政务号不支持；企业认证类型为政府或事业单位的不支持；仅对中国大陆用户开放，且需微信支付绑定身份证实名 | 官方 | 已核实 |
| 入口路径 | 微信 → 发现 → 视频号 → 右上角人像 → 创作者中心 → 创作者服务 → 创作分成计划 → 申请加入 | 官方 | 已核实 |
| 每天实际干什么 | 发布原创视频，并在发布时**开启原创声明**；无需其他额外操作 | 官方 | 已核实 |
| 设备要求 | 手机全程可完成（移动端内登录视频号操作） | 官方 | 已核实 |
| 收入机制 | 原创视频评论区、个人主页视频流展示广告，按广告展示与互动结算分成 | 官方 | 已核实 |
| **收益单价** | 网传「千次有效播放 3–12 元」，来源为非官方聚合站 | 非官方 | **待补** |
| **结算周期与提现门槛** | 官方公开页未列明；收益在「创作者服务 → 创作分成计划 → 参与收益中的视频」中查看 | — | **待补** |
| 权益冻结规则 | 非原创、非优质内容或内容方向变动会导致权益被取消；收到整改通知后需发布 ≥10 条平台认可的优质原创内容方可恢复 | 官方 | 已核实 |
| **时间账** | 取决于起号速度，无公开统计 | — | **待补** |

**待补项清单**：

```
- [待补] 千次有效播放分成单价 —— 官方未公开；需本人开通后实测 7–14 天，
        取「参与收益中的视频」后台数据自建基准
- [待补] 结算周期与提现门槛 —— 官方公开页未列；进入「创作者服务 → 创作分成计划」
        页面查阅规则说明
- [待补] 有效关注 100 的达成耗时 —— 无公开统计；需按本人内容方向实测
- [待补] 个税 / 劳务报酬扣缴口径 —— 需咨询税务专业人士，不在本技能结论范围
```

**最大风险**：该计划为**内测分批邀请制**——满足 100 粉条件也**不保证**能开通；且一旦内容被判非原创，权益会被冻结，恢复需再发布 10 条平台认可的优质原创内容。

### 附：口径冲突处理示范

同一问题，两个第三方来源给出不同说法：

- 来源 A（非官方聚合站）：「0 粉实名认证后即可挂商品链接」
- 来源 B（非官方聚合站）：「需粉丝 ≥1000、原创笔记 ≥10 篇、已实名」

**正确处理**：

```
判定：口径冲突 → 不采信任何一方，转待补
补法：打开 <平台> App → 创作中心 / 合作中心 → 选品中心（或「商品合作」）
      → 以后台实际显示的开通条件为准
禁止：不得用「据说 0 粉就能做」向用户下结论
```

## 四、收益表述红线

报告与说明书中**禁止出现**以下表述：

- 稳赚、保底、包回本、躺赚、包过
- 日入 X 元、月入 X 万（除非该数字有明确来源且已标注）
- 零风险、无脑操作、闭眼入

**正确做法**：写清机制与来源，收益区间标注「官方未公开，待实测」或具体来源链接，让结论可被复核。
