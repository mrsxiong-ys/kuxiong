# 流水线阶段详解

漫画工坊的处理流水线分为 7 个固定阶段（手动编辑模式会扩展为更多阶段）。各阶段顺序执行，支持断点续传（已完成的步骤自动跳过）。

## 标准流水线（7 阶段）

```
解析网址 → 下载图片 → 智能压缩 → OCR 多语言识别 → AI 翻译中文 → 覆盖绘制中文 → 合成 PDF / CBZ
```

## 手动编辑流水线

```
解析网址 → 下载图片 → 智能压缩 → OCR 多语言识别 → AI 翻译中文 → AI 图像清空（手动编辑）→ 等待手动编辑
```

## 图片直译流水线

```
解析网址 → 下载图片 → 智能压缩 → 图片直译（多语言）→ AI 图像清空（手动编辑）→ 等待手动编辑
```

## 各阶段详解

### 1. 解析网址（parseMangaDexUrl）

- 输入：漫画网址 URL
- 识别 MangaDex 链接类型：
  - `/chapter/{36位ID}` → 章节链接
  - `/title/{36位ID}` 或 `/manga/{36位ID}` → 作品链接
  - 其他 MangaDex 链接 → 无法识别
- 非 MangaDex 链接 → 通用网页模式（提取页面图片）
- 输出：漫画标题、章节列表（作品链接）、页数、语言

### 2. 下载图片（downloader）

- MangaDex 章节：调用 `GET /at-home/server/{chapterId}` 获取图片服务器地址，逐页下载
- MangaDex 作品：遍历章节列表，逐章节下载
- 通用网页：解析 HTML 中的图片链接，批量下载
- 支持：代理、超时（默认 60s）、下载间隔（默认 350ms）、User-Agent 伪装
- 输出：`原图/` 目录下的页面图片（按页码排序）

### 3. 智能压缩（compressor）

- sharp 引擎压缩，quality 参数控制（默认 90）
- pageQuality 控制页面显示质量（默认 88）
- 压缩后图片写入临时目录，供后续处理

### 4. OCR 多语言识别（ocr）

- tesseract.js 引擎，本地语言包（由宿主应用随包分发）
- 支持语言：英语（eng）、俄语（rus）、意大利语（ita）、葡萄牙语（por）
- 法语/德语/西班牙语/荷兰语回退到 eng
- 预处理：灰度、对比度增强、小图放大 2 倍、大图（长边>1600）缩小
- word 级结果按行聚合成文本框，输出坐标 + 文字 + 置信度
- OCR 缓存：`.ocr-cache/` 目录，避免重复识别

### 5. AI 翻译中文（translator）

- 两种模式：
  - **OCR 模式**：把 OCR 识别出的台词文本批量发给文本模型翻译
  - **直译模式**：直接把页面图片发给多模态模型，看图识别气泡文字并翻译（跳过 OCR）
- 批量翻译：按 12 条/批分批翻译，失败自动缩批重试（12→8→4→3）
- 输出：每条台词的中文翻译

### 6. 覆盖绘制（overlay / aiRedraw）

- **气泡内覆盖绘制**：在原气泡位置绘制半透明底 + 中文文字（霞鹜文楷字体）
- **AI 图像重绘**：调用图像模型抹除原气泡，再重新绘制中文
- 手动编辑模式：AI 清空气泡区域后，由用户在编辑页手动贴字
- 字体：优先霞鹜文楷（LXGW WenKai），回退思源黑体、微软雅黑

### 7. 合成 PDF/CBZ（composer）

- PDF：pdf-lib 引擎，按页码顺序合成
- CBZ：JSZip 引擎，打包为 ZIP 格式（CBZ 即漫画 ZIP）
- 输出：`{章节名}.pdf` 和/或 `{章节名}.cbz`

## 断点续传机制

- 每个任务写入历史记录（history.json），记录状态（working/done/editing/error）
- 「重新处理」时：
  - 优先恢复编辑会话（磁盘上已有编辑进度则直接接着贴字）
  - 无编辑进度则回填网址重新处理，已下载/压缩/OCR/翻译的步骤自动跳过
- 编辑会话数据：`edit/boxes.json`（台词翻译）、`edit/pages/*.overlay.json`（文字框位置）

## 任务状态

- `working`：处理中
- `done`：已完成
- `editing`：编辑就绪，等待手动编辑
- `error`：处理失败
