# 常见问题与解决方案

## 网址解析失败

### 现象
点击「解析」后提示「无法识别该 MangaDex 链接」或「网址格式不对」。

### 原因与解决
- **网址格式不对**：网址必须以 `http://` 或 `https://` 开头
- **无法识别 MangaDex 链接**：只支持 MangaDex 的章节页（`/chapter/{id}`）和作品页（`/title/{id}` 或 `/manga/{id}`）链接，其他 MangaDex 链接（如搜索页、作者页）不支持
- **MangaDex 链接 ID 必须为 36 位 UUID 格式**（字母数字+连字符）
- **非 MangaDex 网站**：自动进入通用网页模式，仅提取页面图片，不做章节解析

## 下载速度慢 / 超时

### 现象
下载阶段卡住、超时报错、下载的图片不完整。

### 解决
- **配置代理**：在「设置 → 代理」填写可用代理地址（如 `http://127.0.0.1:7890`），MangaDex 服务器在国外，直连可能慢
- **增大下载间隔**：`downloadDelayMs` 默认 350ms，可适当增大（如 500-800ms）避免被限流
- **检查网络**：确认能访问 `api.mangadex.org` 和 `uploads.mangadex.org`
- **代理测试**：先用浏览器测试代理是否可用

## OCR 识别不准确

### 现象
翻译后的中文与原图气泡文字不符、文字框位置偏移、识别文字乱码。

### 原因与解决
- **图片质量差**：低分辨率、模糊、背景复杂的图片识别率低；尝试用「直译模式」让多模态模型直接看图
- **语言包不匹配**：确认章节语言与 OCR 语言包匹配（英语 eng、俄语 rus、意大利语 ita、葡萄牙语 por）；法语/德语/西班牙语/荷兰语回退到 eng，识别率可能下降
- **气泡文字太小**：OCR 预处理会自动放大小图（最小边<1400 时放大 2 倍），但太小的文字仍可能识别失败
- **复杂排版**：多栏、手写体、艺术字识别困难；使用「手动编辑模式」手动贴字
- **坐标偏移**：OCR 在缩放图上识别，坐标已还原到原图坐标系；若仍有偏移，手动编辑模式可手动调整

## 翻译失败 / 超时

### 现象
翻译阶段报错、部分台词翻译失败、返回条数不符。

### 原因与解决
- **API Key 无效**：检查模型配置中的 API Key 是否正确、未过期
- **接口地址错误**：baseURL 必须是 OpenAI 兼容接口（以 `/v1` 结尾，不要带尾部斜杠）
- **模型名错误**：modelName 必须是接口实际支持的模型名（可在「测试」中验证）
- **限流（429）**：翻译间隔 `translateIntervalMs` 增大（如 800→1500ms），或换用限流更宽松的模型
- **返回条数不符**：模型返回的翻译条数与输入台词数不一致；流水线会自动缩批重试（12→8→4→3），极小批仍失败则报错
- **网络问题**：代理配置错误会导致连接超时；直译模式图片以 base64 发送，注意请求体大小限制

## 编辑页无法打开

### 现象
点击「编辑」按钮后页面空白、提示「编辑会话不存在或已过期」。

### 原因与解决
- **任务未完成**：编辑页只在任务「编辑就绪」时可用，需先完成 OCR/翻译并进入手动编辑模式
- **编辑会话过期**：会话保存在内存中，重启软件后丢失；在历史记录中点「重新处理」可恢复编辑进度
- **配置缺失**：手动编辑模式需要图像模型，未配置会报错「手动编辑模式需要配置图像模型」
- **页面路由错误**：编辑页 URL 格式为 `/#/edit/{editId}`，确认 editId 正确

## 断点续传恢复

### 现象
任务中断后想继续处理，或编辑进度想恢复。

### 解决
- **历史记录**：打开「历史」页，找到对应任务
- **编辑就绪状态**：点「重新处理」→ 优先恢复编辑会话（磁盘上编辑数据完好则直接接着贴字）
- **处理中/失败状态**：点「重新处理」→ 回填网址重新处理，已下载/压缩/OCR/翻译的步骤自动跳过
- **编辑数据丢失**：若 `edit/boxes.json` 或 `pages/*.overlay.json` 被删除，编辑进度无法恢复，需从头处理

## 成品文件缺失

### 现象
处理完成后输出目录中没有 PDF/CBZ 文件。

### 原因与解决
- **选项未勾选**：确认设置中 `pdf` 和 `cbz` 已勾选
- **合成失败**：查看任务日志中「合成 PDF / CBZ」步骤是否报错
- **输出路径错误**：确认 `mediaRoot` 路径正确且有写入权限
- **章节数为 0**：解析后没有可下载章节（该漫画可能没有翻译章节）

## 模型连接测试失败

### 现象
添加模型后点「测试」报错。

### 常见错误
- **无法连接到该地址**：网络不通、被墙或域名错误；检查代理或换用其他接口
- **API Key 无效或已过期（HTTP 401）**：重新填写 API Key
- **API Key 无权限（HTTP 403）**：检查账户权限或换用其他模型
- **接口返回异常 HTTP 5xx**：接口服务端问题，稍后重试或换用其他接口
- **模型名不在可用列表**：接口返回的模型列表中没有填写的模型名，更换 modelName

## 通用排查

- **查看错误日志**：应用用户数据目录下漫画工坊的 error.log 文件，记录未捕获异常
- **查看任务日志**：处理过程中的详细日志显示在任务详情页
- **确认依赖完整**：首次运行需执行 `npm install`（含 postinstall 补丁 tesseract.js）
- **版本确认**：`GET /api/version` 或界面标题栏显示版本号
