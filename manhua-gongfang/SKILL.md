# 漫画工坊（Manhua Gongfang）

## 概述

漫画工坊是一个漫画汉化流水线工具，提供从漫画网址到中文漫画成品的一条龙处理能力。支持 MangaDex 站点（作品页/章节页链接）与通用漫画网页两种来源，内置智能压缩、多语言 OCR、AI 翻译、覆盖绘制和 PDF/CBZ 合成。

## 核心能力

1. **网址解析**：解析 MangaDex 作品页（/manga/{id}）与章节页（/chapter/{id}）链接，获取漫画标题、章节列表、语言；也支持通用网页图片提取。
2. **批量下载**：按章节批量下载漫画图片，支持代理、超时、下载间隔控制；MangaDex 走官方 API，通用网页走图片提取。
3. **智能压缩**：sharp 引擎压缩图片，平衡画质与体积。
4. **OCR 多语言识别**：tesseract.js 引擎识别气泡文字，支持英语（eng）、俄语（rus）、意大利语（ita）、葡萄牙语（por），输出带坐标的文本框。
5. **AI 翻译中文**：调用 OpenAI 兼容接口的多模态模型，把识别出的台词批量翻译成自然口语化中文；支持直译（多模态看图直翻）和 OCR 翻译两种模式。
6. **覆盖绘制**：把翻译后的中文文字绘制到漫画气泡位置（气泡内覆盖绘制 / AI 图像重绘抹除原文后重新覆盖两种模式）。
7. **合成 PDF/CBZ**：把处理后的图片合成为 PDF 或 CBZ 阅读文件。
8. **手动编辑**：提供编辑页，用户可手动贴字、调整文字框位置，随时保存进度、断点续传。

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| url | string | 是 | 漫画网址（MangaDex 作品页/章节页，或通用漫画网页） |
| chapterIds | string[] | 否 | 指定下载的章节 ID 列表；留空表示全部章节 |
| mediaRoot | string | 否 | 输出根目录，默认为用户盘下的漫画工坊输出目录（可在设置中修改） |
| quality | number | 否 | 图片压缩质量（0-100），默认 90 |
| pageQuality | number | 否 | 页面图片质量，默认 88 |
| compress | boolean | 否 | 是否智能压缩，默认 true |
| translate | boolean | 否 | 是否翻译，默认 true |
| keepOriginal | boolean | 否 | 是否保留原图，默认 true |
| translateMode | string | 否 | `ocr`（OCR 识别后翻译）或 `direct`（图片直译），默认 `ocr` |
| editManual | boolean | 否 | 是否手动编辑模式（生成编辑会话），默认 false |
| aiRedraw | boolean | 否 | 是否 AI 图像重绘，默认 true |
| pdf | boolean | 否 | 是否生成 PDF，默认 true |
| cbz | boolean | 否 | 是否生成 CBZ，默认 true |
| proxy | string | 否 | 代理地址（如 `http://127.0.0.1:7890`） |
| modelId | string | 否 | 翻译模型 ID（text 类型） |
| imageModelId | string | 否 | 图像模型 ID（image 类型，AI 重绘/直译用） |
| downloadDelayMs | number | 否 | 下载间隔毫秒数，默认 350 |

## 输出结果

- **目录结构**：每部漫画一个项目目录，位于 `mediaRoot/{漫画标题}/` 下，按章节组织：
  - `原图/`：下载的原图
  - `中文/`：处理后的中文图片
  - `temp/`：临时文件
  - `edit/`：编辑会话数据（boxes.json、overlay.json、pages/）
- **成品文件**：每章节生成 `{章节名}.pdf` 和/或 `{章节名}.cbz`
- **任务日志**：任务状态、步骤进度、日志记录
- **历史记录**：处理过的任务列表，支持断点续传（重新处理时自动跳过已完成步骤）

## 调用方式

### 1. 命令行脚本（无头模式）

技能附带 `scripts/mhgf.js` 主流水线脚本，可直接在终端运行：

```bash
node scripts/mhgf.js resolve "https://mangadex.org/chapter/{章节ID}"
node scripts/mhgf.js run "https://mangadex.org/title/{作品ID}" --chapters 1-5
node scripts/mhgf.js translate --input 台词.json --model gpt-4o-mini
node scripts/mhgf.js ocr --input page.jpg --lang eng
node scripts/mhgf.js pack --input dir/ --pdf --cbz
```

### 2. Electron 应用模式

漫画工坊以 Electron 桌面应用形式运行，提供 GUI 界面：
- **首页**：输入网址 → 解析 → 选择章节 → 开始处理
- **编辑页**：手动贴字、调整文字框、保存进度
- **历史页**：查看历史任务、重新处理、断点续传
- **设置页**：配置媒体根目录、压缩/翻译参数、模型管理

### 3. 本地 HTTP API

应用内置 Express 本地服务，暴露 REST API（详见 `references/api.md`）：
- `POST /api/resolve` - 解析网址
- `POST /api/pipeline` - 启动流水线
- `GET /api/jobs/:id` - 查询任务状态
- `POST /api/jobs/:id/cancel` - 取消任务
- `GET /api/edit/:id` - 获取编辑会话
- `POST /api/edit/:id/save` - 保存编辑进度
- `POST /api/edit/:id/finish` - 一键生成成品

## 使用流程

### 快速开始（MangaDex 章节汉化）

1. 在漫画工坊首页输入 MangaDex 章节链接（如 `https://mangadex.org/chapter/xxx`）
2. 点击「解析」确认章节信息（标题、页数、语言）
3. 选择输出格式（PDF/CBZ）和处理选项
4. 点击「开始处理」，等待流水线完成（解析 → 下载 → 压缩 → OCR → 翻译 → 覆盖 → 合成）
5. 在「历史」页查看成品，打开输出目录

### 手动编辑模式

1. 在设置中勾选「✏️ 手动编辑」并配置图像模型
2. 开始处理后，流水线会在 OCR+翻译后暂停，进入「编辑就绪」状态
3. 切换到「编辑」页，逐页手动贴字、调整文字框位置
4. 随时保存进度（自动写入 boxes.json / overlay.json）
5. 点击「一键生成」渲染中文图片并合成 PDF/CBZ
6. 支持断点续传：重启软件后在历史记录点「重新处理」，编辑进度自动恢复

### 图片直译模式

1. 在设置中把翻译模式改为「直译」并勾选「✏️ 手动编辑」
2. 流水线跳过 OCR，直接把页面图片发给多模态模型看图翻译
3. 在编辑页手动贴字（直译跳过 OCR 误差，但需手动确认位置）

## 配置模型

漫画工坊需要配置 AI 模型才能完成翻译和 AI 重绘：

1. 进入「设置 → 模型管理」
2. 添加文本模型（用于翻译）：填写名称、接口地址（OpenAI 兼容）、API Key、模型名
3. 添加图像模型（用于 AI 重绘/直译）：同上，类型选「图像」
4. 点击「测试」验证连接
5. 在设置中选择默认模型

常用模型示例：
- 文本模型：`gpt-4o-mini`、`deepseek-chat`、`qwen-plus`（任何 OpenAI 兼容接口）
- 图像模型：`gpt-4o`、`gpt-4o-mini`、通义万相、即梦等
