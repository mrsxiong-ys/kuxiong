# 人群→产品→包装→内容全套落地框架

目标：用 AI 一条链路完成人群画像、产品表达、包装设计、内容体系，口径统一，不东拼西凑。

## 1. 人群画像（先于一切）

从需求池证据反推，写成可用的画像卡：
- 人群：年龄、性别、场景（例：30~45 女性，婵柔/普拉提学员与教练）
- 审美偏好：从她们的原话和收藏内容判断（低饱和疗愈 / 极简 / 专业感 / 少女感）
- 决策习惯：看测评、看教练推荐、搜索"踩坑"——吃信任型种草
- 购买力：参照她们讨论的同类产品价位
- 一句话画像：`"我是XX的人，我要XX，我讨厌XX，我信XX"`

## 2. 产品表达（从画像倒推）

- 核心卖点：从差异点 + 人群痛点排序（例：保留手部触感 > 不卡虎口 > 透气 > 颜值）
- 一句话 slogan：`专为[场景]设计，[核心价值]，[差异点]`（例：专为婵柔器械螺旋流转设计，稳握流转，保留手部本体触感）
- 卖点排序规则：人群最痛、竞品最弱、我们最强的排第一
- **品牌名（拟注册商标）**：推荐任何品牌名/商标前，必须先让用户到国家知识产权局做近似商标查询并反馈结果，基于查询结果给出可注册性结论；**未查不推荐、修改后未复核不推荐、不可注册一律排除**（详见 `@references/trademark-clearance.md`）。注意：slogan 是营销文案，品牌名是需注册的商标，二者性质不同，**品牌名必须走查询流程，不得跳过**。

## 3. 包装设计（小成本先行）

- 包装语言从人群画像来：色系（低饱和/简约）、材质（纸张/布袋/信封）、文案语气
- 小成本方案（不一开始就做礼盒）：品牌贴纸 + 手感好的信封/纸袋 + 品牌卡（一句话slogan + 使用小贴士）
- 包装也是差异化点之一：与通货的塑料袋包装拉开质感差距
- 合规：包装上不得写医疗功效文案；可印"外观专利申请中"

## 4. 内容体系（一套口径贯穿所有触点）

统一内容资产包：
1. **一句话slogan**：详情页/包装/笔记封面共用
2. **痛点文案**：2~3 条，写"通货的不足→我们的解法"（例：撸铁手套厚垫隔断手感 → 薄基底保留触感）
3. **种草笔记模板**（小红书）：标题（搜索型/痛点型/人群型）+ 正文结构（痛点引入→产品解法→细节特写→版本/尺码→小贴士）
4. **短视频脚本模板**（抖音）：3 秒痛点钩子 → 对比演示 → 细节特写 → 引导（见 `@references/platform-templates.md`）
5. **主图文案**：主图1（产品+定位语）/ 主图2（对比）/ 主图3（细节）/ 主图4（配色+版本）
6. **达人话术包**：置换邀约文案 + 合作内容约束（不写医疗功效）

## 5. 落地顺序

人群画像 → 产品表达（slogan/卖点）→ 包装设计 → 内容体系，每层都引用上一层结论，保证口径一致。产出《视觉+包装+内容资产包》后，进入渠道策略与上架阶段。
