# 工厂技术规格单模板库

发规格单给工厂前：**只发该工厂负责的部分，不给任何一方完整成品方案**（分厂隔离）。规格单与图纸加水印后发出。

---

## 模板 A：成品厂规格单（完整成品定制）

```
【产品名】制作要求
产品定位：一句话定位（例：婵柔专用轻感防滑半指手套，主打保留手部原生触感，不做传统健身手套厚减震垫）
1. 面料
- 手背：____（例：超薄冰丝透气网布，轻薄透气）
- 掌心：____（例：薄款高弹超细纤维，弹力超纤麂皮布，涤纶+氨纶混纺，厚度0.4–0.6mm）
- 禁止项：____（例：无海绵夹层、无加厚减震垫、无魔术贴结构）
2. 工艺
- ____（例：掌心、虎口、指根两侧分区印刷液态硅胶细条纹防滑纹路；硅胶薄涂层，不凸起厚重，出汗不粘手）
3. 版型剪裁
- ____（例：虎口V型开叉剪裁；半指短款露出指尖；窄弹力松紧腕带）
4. 配色：____（列出颜色，注明主推色）
5. 其他要求
- 起订量：____，麻烦按此工艺核算单价
- 请分列报价：①产品单价 ②打样费 ③印花网版/菲林费 ④生产交期
- 产前样确认无误后再安排大货
```

## 模板 B：配件厂规格单（配件定制，只发这一部分）

```
【配件名】制作要求
用途：仅用于____产品内部配件，不对外流通
一、【配件1：____】
1. 基材：____
2. 尺寸：宽__mm，厚__mm
3. 性能要求：____（例：拉伸回弹柔和不勒肉，反复拉伸不易松弛）
4. 配色：____（跟随产品主色）
5. 工艺要求：____（例：边缘锁边平整，无硬凸起，无异味，符合贴身安全标准）
二、【配件2：____】
1. 基材：____
2. 成品厚度：__mm（基材+涂层合计）
3. 纹路：____（例：斜向细条纹，螺旋走向；非圆点）
4. 硅胶位置：仅在指定区域印刷，非满版
5. 性能：____（例：附着力强，水洗多次不易脱落；出汗后不发黏不打滑）
6. 打样交付：先出__组小样（尺寸__×__cm），附水洗测试说明
三、打样要求 & 交付规则
1. 样品归属：全部试样样板所有权属于甲方；乙方仅可自留1份封存对标
2. 文件约束：本规格单、纹路图为甲方专属定制，禁止转发第三方
3. 报价：分开报 ①打样费 ②批量单价 ③菲林/刀模费，模具归属按保密协议执行
4. 交付物：样品 + 材质说明 + 测试简要记录
备注：本厂仅负责该配件生产，不承接成品组装，无需对接其他加工厂
```

## 产前样确认单（收到样品逐项核对签字）

- [ ] 版型：____（例：虎口V口位置、半指长度）与确认稿一致
- [ ] 防滑：纹路结构、位置与参考图一致；附着力测试（指甲刮、水洗1次）不掉胶
- [ ] 面料：手背/掌心材质与规格单一致，厚度达标，无海绵夹层
- [ ] 配色：与色卡一致，无色差
- [ ] 松紧/腕带：穿戴不勒、不松，虎口转动无拉扯
- [ ] 触感：保留手感，不闷汗，无异味
- [ ] 照片存档：正反面各拍一张，作为大货验收标准

## 工厂评估问题清单（对接新工厂时按顺序问）

1. 主业是什么？是否覆盖本产品核心工艺？（不覆盖→降级为配件供应商，分厂隔离）
2. 起订量多少？能否分色排产？（主推色多配量）
3. 报价构成：产品单价 / 打样费 / 印花网版·菲林费 / 交期，分列？
4. 印花网版/菲林所有权是否归我方？大货后封存、无书面通知不启用？
5. 产前样流程：先出每色1只确认样，确认后再大货？
6. 大货抽检标准？残次品如何处理（补发/扣款）？
7. 能否接受保密协议盖章？
