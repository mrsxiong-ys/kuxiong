# 内容场原生诉求挖掘 SOP

目标：从内容平台抓取**用户原生诉求**（真实语境下的吐槽、愿望、提问），而不是电商榜单里已被商业化的信号。

## 为什么不用电商榜单

- 榜单 = 已发生的交易，是红海信号；你看到的爆款已是别人验证过、竞争饱和的位置。
- 内容场 = 正在发生的诉求，是需求源头；用户还没被满足时才会反复表达。
- 判断"能不能做"看原生诉求密度；判断"做什么"看诉求聚类。

## 目标平台与各自价值

| 平台 | 看什么 | 用途 |
|---|---|---|
| 小红书 | 搜索联想词、高互动笔记、评论区 | 诉求最密集、最真实，主力来源 |
| 抖音 | 高赞/高评论视频、评论区 | 抓情绪强度和人群规模 |
| 知乎/B站 | 提问、长回答 | 补充深度痛点与解决方案缺口 |
| 淘宝/京东评论区 | 差评与"求推荐"追问 | 验证现有方案不足（只作佐证，不作起点） |

## 搜索与浏览方法

1. **方向词 + 场景词组合**搜：`方向词`、`方向词+痛点词`、`方向词+避雷/踩坑/求助/求推荐`、`方向词+为什么`。
2. **看搜索联想**：平台自动补全的词就是高频原生诉求（例：输入"婵柔"看到"婵柔手套 推荐""婵柔 手滑"）。
3. **进高互动内容读评论**：评论区是原生诉求富矿——用户会直接说"我也是这样！""求链接""为什么没人做XX"。
4. **记录帖子原文与链接**：每条诉求保留证据（原文摘录+链接），不凭记忆归纳。

## 原生诉求的识别标准

**是原生诉求**：
- 口语化、有具体场景：`"练到第三圈手套开始打滑""这个垫子闻着太味了""有没有那种不勒虎口的"`
- 情绪词：烦、累、丑、土、贵、漏、黏、闷、卡
- 愿望句式：`"要是能……就好了""有没有那种……"`

**不是原生诉求（排除）**：
- 广告话术、种草软文："XX牌YY功能超好用"
- 已被强势品牌教育的表达：用户直接说"买XX牌就行"（说明心智已被占）
- 平台商业化词（竞价词/热门标签），单独出现不算证据

## 聚类需求池

把零散诉求按 **场景 × 痛点 × 人群** 聚类，形成需求池：

```
需求池表格（每条候选一行）
├─ 诉求描述：用户原话总结（例：婵柔练习时手套打滑/卡虎口/太厚没手感）
├─ 证据：帖子/评论原文 + 链接（至少 3 条独立证据）
├─ 出现频次：内容条数与评论条数（量级：零星/稳定/高频）
├─ 情绪强度：吐槽占比（弱/中/强）
├─ 人群画像：从内容语境反推（例：30+女性、婵柔/普拉提学员、审美偏疗愈风）
├─ 现有解决方案及不足：用户当前用什么、为什么不满意
└─ 是否排除：已被品牌教育则标记排除并说明
```

## 输出

需求池表格（含证据链）+ 候选数量 3~6 条，交给阶段 2 品牌真空评估。若需求池为空或全部被排除，回到本阶段换方向词重搜，或回阶段 0 与用户确认方向。
