# 品牌真空评估表

目标：从需求池里选出「**有品类需求、无强势心智品牌**」的位置——用户有真实需求，但说不出"买哪个牌子"。

## 三维度评估

### 1. 需求强度（0~10）
- 出现频次：零星 2~3 / 稳定 6~7 / 高频 8~10
- 情绪强度：吐槽占比、愿望句占比越高越强
- 持续性：是否跨多篇内容、跨平台出现（跨平台=更可靠）
- 给分依据必须是需求池证据，不是感觉。

### 2. 品牌心智空白（0~10，越高越真空）
- 高真空（8~10）：用户表达需求时说不出任何品牌名，只能描述"那种XX"
- 中（5~7）：有品牌但无强势心智，用户会问"XX和YY哪个好"
- 低（0~4）：用户直接说"买XX牌"，心智已被占据 → 直接排除

### 3. 竞争密度（0~10，越低越好）
- 检索该品类内容：数量级、玩家数量、是否有头部账号/品牌、是否有专利护城河
- 低竞争（8~10）：内容少、玩家散、无头部
- 中（5~7）：有若干玩家但都无差异、无心智
- 高（0~4）：头部集中、价格战 → 排除或换细分

## 选品决策表

```
选品决策表（每个候选一行）
├─ 候选：需求池诉求
├─ 需求强度（/10）
├─ 品牌心智空白（/10）
├─ 竞争密度（/10，越高越有利）
├─ 真空结论：是否符合"有品类需求、无强势心智品牌"
├─ 建议产品方向：差异化切入（例：保留手部触感的婵柔专用轻感手套）
├─ 差异化验证：做出什么用户会立刻觉得"这就是我要的"（写具体：材质/结构/纹路/包装）
└─ 主要风险：供应链风险/品类过小/侵权风险等
```

## 选择规则

1. 优先选「需求强度≥7 且 心智空白≥7 且 竞争密度≥7」的候选。
2. 三者都高的候选为空位；若有多个，选需求池证据最密、最接近用户原话的。
3. 心智空白或竞争密度任一低于 5：说明有玩家或已有心智，需换细分切入，或排除。
4. 不要仅凭"我觉得这个有市场"选品，所有分数都要能指出证据来源。

## 输出

选品决策表 + 推荐选项与备选选项，附证据摘要，交给用户确认后进入产品定义阶段。
