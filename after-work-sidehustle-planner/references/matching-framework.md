# 用户画像维度与项目匹配框架

本文件是下班副业规划师 Step 1 / Step 2 的匹配操作手册。核心：**匹配是专家的核心价值，输出必须说明匹配理由。**

## 一、用户画像 8 维度

| 维度 | 问诊要点 | 对匹配的影响 |
|------|----------|--------------|
| 时间 | 每天/每周可投入时长，碎片还是整块 | 碎片→众包/问卷；整块→接单/摆摊/自媒体 |
| 技能 | 可变现技能，无技能直说 | 有技能→技能接单；无技能→众包/摆摊/服务 |
| 本金 | 可动用启动资金 | 0 本金→零成本线上类；有本金→摆摊/技能类 |
| 风险偏好 | 能否接受前期零收入、能否压资金 | 不能压资金→避开囤货类；能接受→可考虑摆摊 |
| 城市 | 所在城市 | 影响摆摊合规、本地行情、点位选择 |
| 能否外出 | 能否出门摆摊 | 能外出→摆摊类；不能→线上类 |
| 设备 | 有无电脑、手机配置 | 有电脑→技能接单/设计/剪辑；仅手机→众包/自媒体 |
| 收益预期 | 期望月收入、能坚持时长 | 校准主攻方向的收益目标与坚持周期 |

## 二、匹配流程

1. **收集**：按 8 维度问诊，输出用户画像摘要请用户确认
2. **过滤**：按硬约束先做排除——
   - 不能外出 → 排除全部摆摊类
   - 本金为 0 → 排除需囤货的摆摊类
   - 不能接受压资金 → 排除囤货类、重投入摆摊
   - 碎片时间（1 小时内） → 排除需要整块时间的接单/摆摊
3. **筛选**：在剩余项目中按技能、收益预期、坚持周期筛选
4. **定档**：选出 1 个主攻 + 2 个备选，备选与主攻在时间/场景上互补

## 三、匹配输出模板

```
# 项目匹配结果
## 用户画像摘要
（确认后的用户画像，8 维度）
## 主攻：<项目名>
**匹配理由**：
- 时间匹配：...
- 技能匹配：...
- 本金匹配：...
- 风险匹配：...
- 场景匹配：...
**预期收益（保守区间）**：...（以核实结果为准）
## 备选 1：<项目名>
**匹配理由**：...（与主攻互补的点）
## 备选 2：<项目名>
**匹配理由**：...（兜底/替代的点）
```

## 四、匹配质量自检

输出前逐条自检：
- [ ] 每个推荐都写了匹配理由，而不是项目简介
- [ ] 没有照搬项目库清单
- [ ] 主攻与备选在场景/时间上互补
- [ ] 收益给的是保守区间，未承诺稳赚
- [ ] 已排除与用户硬约束冲突的项目（如不能外出却推荐摆摊）
