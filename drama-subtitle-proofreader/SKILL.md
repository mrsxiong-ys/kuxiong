# 短剧字幕校对工坊（Drama Subtitle Proofreading Workshop）

## 个人信息隔离（审核红线）

**严禁行为**：
1. 严禁提及或引用开发者昵称、个人账号、个人项目名称等任何个人信息实际值；
2. 严禁即兴编造个性化开场白（如「我是开发者做的短剧字幕工具」「我帮你老东家处理」之类模板之外的个人化表述）；

## 概述

短剧字幕校对工坊是一个短剧字幕校对流水线工具，提供从短剧视频到校对成品的一条龙处理能力。支持三种字幕识别模式（画面OCR / 纯音频ASR / 双通道融合），内置字幕区自动定位、本地OCR、音频转写、台词原文顺序对齐比对、人工修正、效果预览与多种导出格式。

## 核心功能

1. **视频导入与探测**：支持 mp4/mov/mkv/avi/flv/webm 等视频格式，探测时长、宽高、画幅（横屏16:9 / 竖屏9:16 / 4:3 / 3:4）。
2. **字幕区自动定位**：抽低清帧按行水平梯度强度叠加，定位文字字幕带（画面任意位置，中部/顶部/底部均可），替代固定底部裁剪；检测失败回退底部20%。
3. **每秒抽帧 + 字幕条裁剪**：ffmpeg 每秒抽1帧全帧图（frames/），同时裁剪字幕带（strips/），一集两路输出。
4. **本地OCR字幕识别**：tesseract.js 中文（chi_sim），白字提黑+背景去白二值化预处理，超宽字幕带缩小到640px降低wasm峰值；输出文本与置信度，按帧聚合成字幕事件（相邻相似文本合并，噪声帧自动过滤）。
5. **纯音频ASR转写**：sherpa-onnx + SenseVoice 本地离线，视频→16k单声道wav→22s步进分块→逐块离线识别→token级时间戳→按停顿切分字幕行（时间轴以音频为准）。
6. **双通道融合**：以画面字幕为行边界（画面切换即字幕换行），ASR字级时间戳按画面段重新分行，输出既有画面时间轴又有语音文本的字幕事件。
7. **台词原文比对**：识别字幕与台词原文逐条顺序对齐（归一化+编辑距离相似度），有差异的行整行高亮，同时列出「漏检」（原文有、识别未出现）与「多余」（识别出现、原文没有）行；同音错字能检出。
8. **人工修正**：差异行可直接编辑（默认填入原文建议），点击任意行查看该时刻画面；修正后即时反映到导出。
9. **效果预览播放**：内置效果预览播放器，原生播放器叠加修正后字幕，兼容多种画幅，支持进度拖动与倍速，改字即时反映。
10. **烧录字幕视频**：ffmpeg 把修正后字幕烧录进新视频、保留原声；默认先遮盖底部字幕区再烧录（避免新旧字幕重叠，可取消勾选）；竖屏字幕在中部时动态遮罩字幕带位置。
11. **多格式导出**：SRT（用修改后文本）、校对报告（错误清单+时间轴+漏检/多余明细）、CSV事件表（序号/开始/结束/识别字幕/台词原文/修改后/状态）。
12. **项目化管理**：每集一个项目文件夹（frames/全帧、strips/字幕区裁剪、output/导出、events.json校对进度），支持断点续传。

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| videoPath | string | 是 | 短剧视频路径（mp4/mov/mkv/avi/flv/webm） |
| scriptPath | string | 否 | 台词原文文件路径（txt每行一句 / srt带时间轴 / ass） |
| mode | string | 否 | 识别模式：`ocr`（画面OCR，默认）/ `asr`（纯音频ASR）/ `fusion`（双通道融合） |
| projectDir | string | 否 | 项目目录，默认自动创建 `D:\短剧字幕校对工坊\{项目名}` |
| projectName | string | 否 | 项目名称，默认取视频文件名 |
| maskBottom | number | 否 | 烧录时底部遮盖比例（横屏默认0.22，竖屏无字幕带检测时0.3） |
| maskOriginal | boolean | 否 | 烧录前是否遮盖原字幕区（默认true，避免新旧字幕重叠） |

## 输出结果

- **项目目录结构**：每集一个项目文件夹，位于 `{projectDir}/` 下：
  - `frames/`：每秒抽帧的全帧图（f_0001.png, f_0002.png, ...）
  - `strips/`：字幕区裁剪图（s_0001.png, ...）
  - `output/`：导出文件
  - `events.json`：字幕事件与校对进度
  - `zone.json`：字幕区检测结果（y0, y1 相对高度）
- **成品文件**：
  - `output/{项目名}.srt`：校对后的SRT字幕
  - `output/{项目名}.mp4`：烧录字幕的视频（保留原声）
  - `output/{项目名}-校对报告.txt`：校对报告（错误清单+时间轴+漏检/多余明细）
  - `output/{项目名}-事件表.csv`：CSV事件表
- **比对结果**：JSON 结构化数据，包含 rows（匹配行，含 ocrText/scriptText/similarity/isDiff/suggested/diffChars）、missing（漏检）、extra（多余行）
- **字幕事件**：数组，每项含 start/end（秒）、frameIndex、text、source（ocr/asr/frame）

## 调用方式

### 1. 命令行脚本（无头模式）

技能附带 `scripts/zimu.js` 主流水线脚本，可直接在终端运行：

```bash
# 探测视频信息
node scripts/zimu.js probe "视频路径.mp4"

# 完整校对流水线（默认OCR模式）
node scripts/zimu.js run "视频路径.mp4" --script "台词.txt" --mode ocr

# 纯音频ASR模式
node scripts/zimu.js run "视频路径.mp4" --script "台词.txt" --mode asr

# 双通道融合模式
node scripts/zimu.js run "视频路径.mp4" --script "台词.txt" --mode fusion

# 仅比对（已有字幕事件文件）
node scripts/zimu.js align --events events.json --script "台词.txt"

# 导出SRT
node scripts/zimu.js export-srt --events events.json --out output/字幕.srt

# 烧录字幕视频
node scripts/zimu.js burn "视频路径.mp4" --events events.json --out output/带字幕.mp4

# 导出校对报告
node scripts/zimu.js export-report --events events.json --out output/报告.txt

# 导出CSV事件表
node scripts/zimu.js export-csv --events events.json --out output/事件表.csv
```

### 2. Electron 应用模式

短剧字幕校对工坊以 Electron 桌面应用形式运行，提供 GUI 界面：
- **校对页**：导入视频+台词原文 → 识别字幕 → 比对标色 → 逐行修正
- **预览页**：效果预览播放器，叠加修正后字幕播放
- **历史页**：查看历史项目、重新处理、断点续传
- **设置页**：配置项目根目录、识别模式、烧录参数

### 3. IPC 接口（Electron 内部）

应用主进程暴露 IPC 接口：
- `pipeline:run` - 一键流水线（抽帧 → OCR/ASR → 事件分组）
- `script:parse` - 解析台词原文文件
- `align:run` - 执行字幕与原文比对
- `events:save` / `events:load` - 保存/加载校对进度
- `frame:read` - 读取指定帧画面（base64）
- `export:srt` / `export:report` / `export:csv` - 导出各类成品
- `export:burn` - 烧录字幕视频

## 使用流程

### 快速开始（OCR模式校对）

1. 导入短剧视频（mp4/mov/mkv 等）+ 台词原文文件（txt 每行一句，或 srt 带时间轴）
2. 选择识别模式（默认OCR画面识别）
3. 执行流水线：抽帧 → 字幕区定位 → OCR识别 → 事件分组 → 原文比对
4. 逐行检查比对结果：差异行橙色高亮，可编辑修正；查看漏检/多余列表
5. 预览播放器播放一遍，确认修正后字幕效果
6. 导出成品：SRT / 烧录字幕视频 / 校对报告 / CSV

### ASR音频模式

1. 适用于画面无字幕或画面字幕质量差的短剧
2. 选择 ASR 模式，工具自动从视频提取音频转写
3. 时间轴以音频为准，按停顿切分字幕行
4. 与台词原文比对校对
5. 导出 SRT 或烧录字幕视频

### 双通道融合模式

1. 同时执行画面OCR + 音频ASR
2. 以画面字幕切换为行边界（画面变了字幕就换）
3. ASR字级时间戳分配到所属画面字幕段
4. 输出既有画面时间轴又有语音文本的字幕事件
5. 适合画面字幕与语音并存的短剧

### 烧录字幕视频

1. 在校对页完成字幕修正
2. 点击「烧录字幕视频」
3. 工具自动检测字幕区位置（zone.json），动态遮罩原字幕
4. ffmpeg 生成 ASS 字幕 → 烧录进新视频 → 保留原声
5. 竖屏短剧字幕在中部时，遮罩区域自动适配，避免新旧字幕重叠

## 配置要求

### 资产边界（重要）

本技能包是 **AI 专家的指令与工作流资产**，仅包含 Markdown 文档、专家配置和一个 Node 命令行脚本，**不内置任何二进制模型或可执行程序**。以下资源均由**宿主「短剧字幕校对工坊」桌面工程**在运行时提供或首次启用时自动下载，不属于本包资产、也不随包分发：

| 外部依赖 | 提供方 | 说明 |
|---|---|---|
| 中文 OCR 识别语言包（chi_sim） | 宿主工坊工程 | 首次启用 OCR 时自动下载并缓存到本地数据目录 |
| SenseVoice 离线 ASR 模型、词表与推理程序 | 宿主工坊工程 | 首次启用 ASR 时自动下载（约 237MB），缓存于本机应用数据目录 |
| ffmpeg 便携版 | 宿主工坊工程 | 随工坊程序一起安装 |
| `core/` 等核心模块 | 宿主工坊工程 | 由 `ZIMU_HOME` 定位，命令行脚本运行时动态加载 |

若本机尚未安装工坊程序，请先安装 **短剧字幕校对工坊 v1.7.1 桌面版**，再使用本专家技能。包内 `scripts/zimu.js` 只是调用宿主工程的无头入口，不重复携带上述文件。

### 环境变量

- `ZIMU_HOME`：短剧字幕校对工坊工程根目录（含 core/ 目录），默认自动查找
  - 查找顺序：环境变量 ZIMU_HOME → 常见安装路径 → `D:\短剧字幕校对工坊`
- `ZIMU_PROJECT_ROOT`：项目数据根目录，默认 `D:\短剧字幕校对工坊`

### 识别模式选择

| 模式 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| OCR（默认） | 画面有清晰硬字幕 | 时间轴精准（跟随画面）、无需音频 | 画面无字幕时无法识别 |
| ASR | 画面无字幕或字幕质量差 | 画面无字幕也能识别、纯音频转写 | 时间轴以音频为准、可能与画面不完全同步 |
| Fusion（融合） | 画面字幕与语音并存 | 时间轴跟随画面、文本来自语音、最准确 | 耗时最长（OCR+ASR都跑） |

## 注意事项

- 本工具仅用于个人学习与字幕校对工作，请遵守相关视频的使用条款和版权规定
- OCR识别准确度受视频清晰度与字体影响，复杂排版可能需要人工修正
- 抽帧按1秒1帧，字幕停留不足1秒的快速台词可能漏抽
- ASR转写为本地离线模型，中文短剧优化，其他语言效果可能下降
- 烧录字幕会遮盖原字幕区，请确认遮罩范围后再导出
- 处理过程中请勿关闭软件，以免中断任务（支持断点续传）
