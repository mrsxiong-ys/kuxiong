# 流水线阶段详解

短剧字幕校对工坊的处理流水线根据识别模式不同分为三个分支，各阶段顺序执行。

## OCR 流水线（默认）

```
视频探测 → 字幕区检测 → 每秒抽帧 → 字幕条裁剪 → OCR识别 → 事件分组 → 台词原文比对 → 人工修正 → 导出
```

## ASR 流水线

```
视频探测 → 提取音频 → sherpa-onnx转写 → token级时间戳 → 按停顿切行 → 台词原文比对 → 人工修正 → 导出
```

## Fusion 流水线（双通道融合）

```
视频探测 → 字幕区检测 → 每秒抽帧 → 字幕条裁剪 → OCR识别 → 事件分组
                                            → 提取音频 → sherpa-onnx转写 → token级时间戳
                                            → 画面段行边界 + ASR文本分配 → 融合字幕事件 → 台词原文比对 → 人工修正 → 导出
```

## 各阶段详解

### 1. 视频探测（probeVideo）

- 输入：视频路径
- 调用 ffprobe 读取视频信息
- 输出：时长（duration）、宽高（width/height）
- 用途：确定画幅（横屏宽>高 / 竖屏宽<高），为字幕烧录字号和遮罩策略提供依据

### 2. 字幕区检测（detectZone）

- 输入：视频路径
- 抽低清帧（fps=1, scale=430:-2，最多30帧覆盖前30秒）
- 按行水平梯度强度叠加，定位文字字幕带
- 忽略画面上半部（MIN_Y=0.34，字幕通常在下半部，避免人脸/场景噪声）
- 返回 `{ y0, y1 }`（0~1 相对高度）
- 检测失败返回 null（调用方回退默认底部20%裁剪）
- 结果存入 `zone.json`，烧录时用于动态遮罩

### 3. 每秒抽帧（extractFrames）

- 输入：视频路径、项目目录
- ffmpeg 每秒抽1帧全帧图：`fps=1` → `frames/f_%04d.png`
- 同时裁剪字幕带：`fps=1,crop=iw:ih*(y1-y0):0:ih*y0` → `strips/s_%04d.png`
- 字幕区检测失败时回退：`crop=iw:ih*0.2:0:ih*0.8`（底部20%）
- 输出：frames/（全帧）、strips/（字幕条）

### 4. OCR识别（recognizeBatch）

- 输入：字幕条文件列表（strips/）
- tesseract.js 中文识别（chi_sim 语言包）：语言包由**宿主工坊工程**在首次启用 OCR 时自动下载并缓存到本地数据目录，属于运行时外部依赖，不是本技能包的内置资源
- 预处理：白字提黑 + 背景去白（亮度阈值二值化）
  - 亮色文字占比 < 2%：灰度直送（深色/彩色字幕场景）
  - 亮色文字占比 > 60%：阈值提高到205
  - 阈值默认185：>阈值→黑字，其余→白底
- 超宽字幕带（宽度>640px）缩小到640px，降低wasm峰值
- 常驻单worker串行执行（避免逐批重建叠加语言包内存）
- 单帧异常：重建worker继续下一帧，不中断整批
- 识别结束立即释放wasm内存
- 输出：每帧的 `{ text, conf }`

### 5. 事件分组（groupEvents）

- 输入：OCR帧结果数组（顺序=帧序）
- 噪声帧过滤：汉字占比 < 55% 的帧视为无字幕（背景残留/乱码）
- 相邻帧文本相同/相似（相似度≥0.75）合并为同一字幕事件
- 输出：字幕事件数组 `{ start, end, text, frameIndex, frames }`
  - start/end 单位为秒（帧索引=秒数）
  - frames 包含该事件覆盖的所有帧索引

### 6. ASR音频转写（transcribe）

- 输入：视频路径
- 提取16k单声道wav音频
- sherpa-onnx + SenseVoice 本地离线模型
- 22秒步进分块（25秒块长含尾部3秒重叠，防止块尾截断词）
- 逐块离线识别，输出token级时间戳
- 按停顿切行（token间隔>0.45秒视为语义停顿）
- 行最短时长1.2秒（太短吞并到下一行）
- 行最长字数26字（超长按字组补切）
- 相邻行时间不重叠（前一行在下一行开始时结束）
- 输出：字幕行数组 `{ start, end, text }`

### 7. 双通道融合（build）

- 输入：ASR转写结果 + OCR帧结果 + 视频时长
- OCR帧文本先做噪声过滤（汉字占比 < 45% 的帧丢弃）
- 画面字幕分段：相邻帧文本相同/相似视为同一画面字幕段
- 文本变化 = 画面字幕切换 = 行边界
- ASR字级时间戳按时间分配到所属画面字幕段
- 输出：融合字幕事件 `{ start, end, frameIndex, text, asrText, frameText, source }`
  - source: 'frame'（画面分段，主文本来自语音）/'asr'（画面无字幕，纯语音退化行）/'ocr'（仅画面字幕无语音）

### 8. 台词原文比对（align）

- 输入：字幕事件数组 + 台词原文条目数组
- 归一化：去除空白、标点、全角转半角、小写
- 编辑距离相似度计算
- 顺序对齐：MATCH阈值0.55，LOOSE阈值0.35
- 输出：
  - rows（匹配行）：`{ start, end, frameIndex, ocrText, scriptText, similarity, isDiff, suggested, diffChars, diffStatus }`
  - missing（漏检）：原文有、识别未出现
  - extra（多余）：识别出现、原文没有

### 9. 人工修正（GUI）

- 差异行橙色高亮（isDiff=true）
- 修改后填入 editedText 字段
- 点击行查看该时刻画面（frame:read 返回base64）
- 保存到 events.json

### 10. 导出

| 导出类型 | 函数 | 说明 |
|---------|------|------|
| SRT | exportSrt | 用修改后文本，格式 `序号\n时间轴 --> 时间轴\n文本\n\n` |
| 校对报告 | exportReport | 错误清单（时间轴+识别字幕+原文+修改后）+ 漏检列表 + 多余行列表 |
| CSV事件表 | exportCsv | 序号/开始/结束/识别字幕/台词原文/修改后/状态，带BOM头 |
| 烧录视频 | burnSubtitles | 生成ASS → ffmpeg libass烧录 → 保留原声 |

## 输出目录结构

```
{projectDir}/{项目名}/
├── frames/
│   ├── f_0001.png
│   ├── f_0002.png
│   └── ...
├── strips/
│   ├── s_0001.png
│   ├── s_0002.png
│   └── ...
├── output/
│   ├── {项目名}.srt
│   ├── {项目名}.mp4
│   ├── {项目名}-校对报告.txt
│   └── {项目名}-事件表.csv
├── events.json
└── zone.json
```

## 任务状态

- `working`：处理中
- `done`：已完成
- `error`：处理失败

## 断点续传机制

- 每个项目写入 events.json（字幕事件与校对进度）
- 重新处理时：
  - 优先恢复编辑会话（events.json 已有校对进度则直接接着修正）
  - 无校对进度则重新识别（已抽帧/已识别的步骤可跳过）
- 识别结果缓存在项目目录（frames/、strips/），重新识别不需要重新抽帧
