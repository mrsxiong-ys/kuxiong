# 三种识别模式完整说明

短剧字幕校对工坊提供三种字幕识别模式，用户可根据短剧的字幕情况选择最合适的模式。

## OCR 模式（默认）

### 原理

从视频每秒抽1帧，自动定位字幕区（画面任意位置），裁剪字幕条，用 tesseract.js 本地OCR识别中文文字，按帧聚合成字幕事件。

### 适用场景

- 短剧画面有清晰硬字幕（烧录在画面里的字幕）
- 字幕位置可能在画面中部（竖屏短剧常见）、顶部或底部
- 台词与画面字幕基本一致

### 优点

- 时间轴精准：跟随画面切换，字幕何时出现何时消失一目了然
- 无需音频：即使视频没有音轨也能识别
- 本地离线：OCR模型随包分发，无需联网

### 缺点

- 画面无字幕时无法识别（只能识别画面里看得见的文字）
- 字幕被遮挡、模糊、艺术字体时识别准确度下降
- 字幕停留不足1秒的快速台词可能漏抽（每秒1帧）

### 技术细节

- 字幕区检测：抽低清帧（fps=1, scale=430:-2），按行水平梯度强度叠加定位文字带
- OCR预处理：白字提黑 + 背景去白二值化（亮度阈值185/205）
- 超宽字幕带缩小到640px，降低wasm峰值
- 常驻单worker串行执行，避免内存叠加
- 噪声帧过滤：汉字占比 < 55% 的帧视为无字幕

### 调用方式

```bash
node scripts/zimu.js run "视频路径.mp4" --script "台词.txt" --mode ocr
```

## ASR 模式（纯音频）

### 原理

从视频提取音频（16k单声道wav），用 sherpa-onnx + SenseVoice 本地离线模型转写，token级时间戳按停顿切分字幕行，时间轴以音频为准。

### 适用场景

- 短剧画面没有硬字幕，但有清晰台词
- 画面字幕质量差、被遮挡、识别不准
- 需要纯语音转文字

### 优点

- 画面无字幕也能识别
- 时间轴以音频为准，与语音同步
- 本地离线：ASR模型随包分发，无需联网

### 缺点

- 时间轴以音频为准，可能与画面切换不完全同步
- 多人同时说话时可能混淆
- 方言、口音重的普通话效果可能下降
- 需要视频有清晰音轨

### 技术细节

- 本地 sherpa-onnx 离线推理 + SenseVoice 中文模型（模型由**宿主工坊工程**首次启用 ASR 时自动下载并缓存，约 237MB，不是本技能包的内置资源）
- 22秒步进分块（25秒块长含尾部3秒重叠，防止块尾截断词）
- token间隔 > 0.45秒视为语义停顿，切分行
- 行最短时长1.2秒（太短吞并到下一行）
- 行最长字数26字（超长按字组补切）
- 相邻行时间不重叠
- 模型缓存目录位于本机应用数据目录（须为纯 ASCII 路径，避免中文路径损坏）

### 调用方式

```bash
node scripts/zimu.js run "视频路径.mp4" --script "台词.txt" --mode asr
```

## Fusion 模式（双通道融合）

### 原理

同时执行画面OCR + 音频ASR。以画面字幕切换为行边界（画面变了字幕就换），ASR字级时间戳按时间分配到所属画面字幕段。输出既有画面时间轴又有语音文本的字幕事件。

### 适用场景

- 短剧画面有字幕且台词与字幕基本一致
- 希望时间轴跟随画面（而非音频），但文本内容以语音为准（更准）
- 画面字幕可能识别不准，但语音清晰

### 优点

- 时间轴跟随画面切换（比ASR更准）
- 文本内容来自语音（比OCR更准）
- 综合两种模式的优点

### 缺点

- 耗时最长（OCR+ASR都跑）
- 需要视频既有字幕又有清晰音轨
- 实现复杂度最高

### 技术细节

- OCR帧文本先做噪声过滤（汉字占比 < 45% 的帧丢弃）
- 画面字幕分段：相邻帧文本相同/相似视为同一画面字幕段
- 文本变化 = 画面字幕切换 = 行边界
- ASR字级时间戳按时间分配到所属画面字幕段
- 输出事件 source 字段：
  - 'frame'：画面分段，主文本来自语音
  - 'asr'：画面无字幕，纯语音退化行
  - 'ocr'：仅画面字幕无语音（如语气词画面）

### 调用方式

```bash
node scripts/zimu.js run "视频路径.mp4" --script "台词.txt" --mode fusion
```

## 模式选择决策树

```
短剧有硬字幕吗？
├── 有 → 字幕清晰吗？
│   ├── 清晰 → OCR模式（默认，时间轴最准）
│   └── 不清晰/被遮挡 → 有清晰台词吗？
│       ├── 有 → Fusion模式（画面定行+语音定文本）
│       └── 无 → ASR模式（纯语音转写）
└── 无 → 有清晰台词吗？
    ├── 有 → ASR模式
    └── 无 → 无法识别（无字幕无语音）
```

## 模式对比表

| 维度 | OCR | ASR | Fusion |
|------|-----|-----|--------|
| 画面字幕需求 | 必须有 | 不需要 | 必须有 |
| 音频需求 | 不需要 | 必须有 | 必须有 |
| 时间轴来源 | 画面 | 音频 | 画面 |
| 文本来源 | OCR识别 | ASR转写 | ASR转写 |
| 准确度 | 字幕清晰时高 | 语音清晰时高 | 综合最高 |
| 耗时 | 短 | 中 | 长 |
| 内存占用 | 高（wasm OCR） | 中（ASR模型） | 最高 |
| 离线 | 是 | 是 | 是 |
